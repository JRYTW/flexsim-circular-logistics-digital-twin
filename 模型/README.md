# 模型操作

## 開啟

使用 FlexSim 2027 開啟[循環物流.fsm](循環物流.fsm)。模型存於停止狀態，模擬時間為0；預設短波尖峰情境（S1）、聯合改善方案（P4）及12公尺緩衝。

若沒有3D畫面，新增透視視窗（Perspective View）。先在停止狀態查看佈局，再依需要使用重設（Reset）與運行（Run）。模型的動態績效與所附研究數據的適用範圍，見[信效度報告](../重點檔案/信效度報告.md)。

## 儀表板

開啟模型時會顯示「作業總覽」。工具箱（Toolbox）的儀表板（Dashboards）分類另有「設備與人員」、「箱資產與能耗」、「指標明細」及「參數設定」。畫面約每0.5秒讀取模型；排程量測欄位仍依模型排程更新。可將儀表板拖到3D畫面旁，或拖出為獨立視窗。欄位範圍、單位與操作方式見[儀表板說明](儀表板說明.md)。

## 觀看順序

1. 全景：辨識地面商品線與上層洗箱線。
2. 正面低視角：檢查平台、工位與輸送帶的支撐及高度。
3. 左右側：檢查上行、下行輸送帶與包裝交接。
4. 背面：查看樓梯、護欄及上層工作區。
5. 俯視與近景：查看商品分級、合流、清洗及空箱回流。

從3D視窗工具列選擇旋轉／環繞、平移與縮放。鼠鍵操作會依軟體設定而不同；不要只看單一鳥瞰圖判斷設備是否接合。對照[多視角圖片](../重點檔案/模型畫面/)及[展示指南](../重點檔案/展示指南.md)。

## 中文字型

若文字呈現方框，確認電腦已安裝微軟正黑體。在樹狀檢視（Tree View）的 **VIEW → environment → fonts → threedviews → name** 設定 `msjhbd.ttc`，儲存環境偏好設定，再完整關閉並重開 FlexSim。這是軟體的3D字型設定；不需更改中文物件名稱。

## 修改設定

需求情境、改善方案與緩衝長度位於參數表（Params）。更動參數後須讓配置與需求初始化程序同步生效；只改可見物件的位置，不等於改變了實際物流連線。建議先另存工作檔，再調整參數或處理時間。

預設配置的幾何已檢查，重開及重設後位置一致。這不等於已驗證所有自訂配置，也不代表所有負載下都不會卡住。外包清洗以廠區外延遲流程表示，並未建立完整外部運輸動畫。
