| 模型 | 預設配置 | 用途 |
|---|---|---|

兩份均預設短波尖峰情境（S1）、五名人員、500個循環箱及種子101，使用相同流程與指標計算。改善前模型沿用相同的顏色與儀表板修正，差異在實驗配置；第二台清洗機保留物件，但未啟用。開啟後先重設（Reset），再運行（Run）。

使用 FlexSim 2027 開啟[循環物流.fsm](循環物流.fsm)。模型存於停止狀態，模擬時間為0；預設短波尖峰情境（S1）、聯合改善方案（P4）及12公尺緩衝。

若沒有3D畫面，新增透視視窗（Perspective View）。先在停止狀態查看佈局，再依需要使用重設（Reset）與運行（Run）。本次完整實驗採同一實體輸送模型，其數據期間與適用範圍見[信效度報告](../重點檔案/信效度報告.md)。

## 儀表板

開啟模型時會顯示「作業總覽」。工具箱（Toolbox）的儀表板（Dashboards）分類另有「設備與人員」、「箱資產與能耗」、「指標明細」及「參數設定」。畫面約每0.5秒讀取模型；排程量測欄位仍依模型排程更新。可將儀表板拖到3D畫面旁，或拖出為獨立視窗。欄位範圍、單位與操作方式見[儀表板說明](儀表板說明.md)。

## 觀看順序

1. 全景：辨識地面商品線與上層洗箱線。
2. 正面低視角：檢查平台、工位與輸送帶的支撐及高度。
3. 左右側：檢查上行、下行輸送帶與包裝交接。
4. 背面：查看樓梯、護欄及上層工作區。
5. 俯視與近景：查看商品分級、合流、清洗及空箱回流。

從3D視窗工具列選擇旋轉／環繞、平移與縮放。鼠鍵操作會依軟體設定而不同；不要只看單一鳥瞰圖判斷設備是否接合。對照[多視角圖片](../重點檔案/模型畫面/)及[展示指南](../重點檔案/展示指南.md)。

## 中文字型

若文字呈現方框，確認電腦已安裝微軟正黑體。在樹狀檢視（Tree View）的 **VIEW → environment → fonts → threedviews → name** 設定 `msjhbd.ttc`，儲存環境偏好設定，再完整關閉並重開 FlexSim。這是軟體的3D字型設定；不需更改中文物件名稱。

## 修改設定

需求情境、改善方案與緩衝長度位於參數表（Params）。更動參數後須讓配置與需求初始化程序同步生效；只改可見物件的位置，不等於改變了實際物流連線。建議先另存工作檔，再調整參數或處理時間。

預設配置的幾何已檢查，重開及重設後位置一致。這不等於已驗證所有自訂配置，也不代表所有負載下都不會卡住。外包清洗以廠區外延遲流程表示，並未建立完整外部運輸動畫。

## 顏色與實驗配置

循環箱綠色、尚未取得資產的外部箱類請求灰色；商品未檢灰色，A級藍、B級黃、C級紅，新單白色。商品在箱內可能被外箱遮住。

需求、改善方案與緩衝長度是三個不同設定，完整定義見[共用對照](../名詞與代碼對照.md)。模型內批次任務「需求與方案完整比較」為45種配置各30次；「基準精度600次」為平日基準、現況、1公尺的精度任務。新跑實驗會重新累積結果；發布的完整本次數據見[數據導覽](../重點檔案/數據/README.md)。

## 重跑批次實驗

先在模型同層建立名為 `experiment_exports` 的資料夾，供原生暖機與結束讀值寫出。再開啟批次實驗工具（Experimenter），選擇「需求與方案完整比較」或「基準精度600次」。前者45種配置各30次，後者為平日現況1公尺的600次；相同任務可共用前30次結果。

暖機由模型在24小時的事件自行記錄並排除，因此批次工具預覽的暖機時間為0；不要再額外設定24小時而重複排除。隨附CSV是本次完整比較結果，模型內的任務設定供自行重跑。

較高短波尖峰情境（S1_4.5）的270件／小時由需求產生程序指定；僅修改參數表中的一般尖峰到達率，不會改變此情境的270件設定。
