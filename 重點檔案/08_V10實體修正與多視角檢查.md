# 實體修正與多視角檢查｜修正版（V10）

本次處理使用者指出的浮空、輸送帶斷開與不合理佈局。依使用者停止實驗的指示，後續只做重設、幾何讀取、靜態視角檢查與存檔；沒有再啟動模擬、動畫短跑或批次實驗。開啟方式見[模型導覽](../模型/README.md)。

## 為什麼不是只換材質

先前版本有些交接只有邏輯連線，畫面沒有相應搬運路徑。這次新增20段原生輸送帶，總數27段；也加入有限容量的合流工作單元。這會改變運搬時間、阻塞與能耗，因此舊版正式結果不再代表新版。

下降帶原本錯把原生物件的外框底部高度當成起點高度。現在下降回流帶起點在5公尺、終點在1公尺，底部位置設在1公尺；平台面在4公尺。平台止於下降段前方，避免整片樓板穿過下降帶。

## 這次改了哪些地方

| 問題 | 修正 | 如何檢查 |
|---|---|---|
| 機台與輸送段看起來漂浮 | 加入平台支柱、輸送帶支腳、工作台腳及空箱架 | 正面低視角與左右側視角檢查支腳是否到地面／平台 |
| 下行輸送帶高度不對 | 修正起終點高度與原生外框底部的關係 | 右側視角、包裝近景 |
| 分級之間只有邏輯交接 | 補上品質檢查至各級、各級至合流的原生輸送帶 | 俯視與分級近景 |
| 多路合流不合理 | 改為有8件容量的分級合流工作單元，分開接收各路商品 | 分級近景與平台剖視 |
| 人員穿進工作台 | 將五名人員的初始位置移到台側 | 重設後近景檢查；這不代表已驗證負載下的全部行走軌跡 |
| 外包示意設備像孤立機台 | 將模型邊界外的延遲節點移出廠區並隱藏外形 | 廠內不再顯示一台沒有實體運輸路徑的外包機台 |
| 版面中的預設綠色機台難辨識 | 換成帶控制面板與支腳的工位、清洗設備外殼 | 上層與分級近景 |

待檢區容量24件、B級待處理區8件、商品合流區8件、分級合流工作單元8件。原有五名人員、500個實體循環箱的教學設定保留；新增輸送段的馬達功率以每段0.12千瓦估計，尚無供應商校準。

## 幾何檢查代表什麼

27段原生輸送帶均讀取實際起終點、寬度、水平長度及爬升量，斜面長度符合其幾何關係。其中26段符合放置計畫的端點；A級合流的原生接口自動貼齊，使端點各座標最大偏移約0.235公尺，但實際帶面末端仍與接收工作單元相交，沒有開口。詳見[幾何檢查資料](驗證摘要/V10_輸送帶幾何檢查.json)。

計算中使用的微小容許誤差是電腦座標核對標準，不是實倉量測精度。不同帶寬交接的導引、護罩、料件尺寸、結構承載、消防動線及設備維修空間，仍須依實際設備圖面設計；本次沒有把它宣稱成施工圖或法規認證。

## 版本怎麼分，什麼還不能說

本次四個主要模型已換成實體修正版（V10）。舊版完整模型與同名結果資料庫另存為「歷史V8_實驗完整結果」，原檔數值不變。

原報告的1350次主實驗、600個基準樣本、12公尺建議、減碳、直接投資報酬率與舊動畫，都只屬於歷史計算版本（V8）。停止指示之前曾有新版試跑與未完成批次，未作為本次正式統計成果公開；最終又調整了工位外觀、人員初始站位與外包示意位置，因此不能把早先試跑當成最終檔的完整驗證。

**本次完成的是實體佈局修正、靜態多視角檢查與安全發布；不是新版正式實驗結論。** 最終版負載下的守恆、尋路防死鎖、即時儀表板與投資最佳方案，仍未重新完成動態驗證。未經實倉資料校準，也沒有新增正報酬宣稱。
