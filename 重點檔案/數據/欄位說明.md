# 數據欄位說明

逐次主實驗與基準精度表各有75欄，每列是一次完整模擬，不是30次平均。情境、方案與長度依[共同定義](../../名詞與代碼對照.md)。

| 原始欄名 | 中文意思 | 單位與限制 |
|---|---|---|
| `scenario` | 需求情境代碼 | 平日基準情境（S0）；短波尖峰情境（S1）；較高短波尖峰情境（S1_4.5）。 |
| `prescription` | 改善方案代碼 | 維持現況方案（P0）；增設第二台清洗機方案（P1）；緩衝長度調整方案（P2）；外包清洗方案（P3）；聯合改善方案（P4）。 |
| `buffer_m` | 緩衝長度 | 公尺；不是分鐘；0表示真旁路 |
| `replication` | 重複模擬編號 | 同一配置的第幾次完整模擬 |
| `seed` | 隨機種子 | 控制隨機序列以便重現 |
| `duration_s` | 觀察期長度 | 秒；正式主實驗為518400秒，即暖機後6日 |
| `returns` | 退貨到達量 | 件；觀察期外部到達的退貨需求 |
| `new_goods` | 新單商品到達量 | 件；與退貨商品分開 |
| `shipped_returns` | 退貨商品出庫量 | 件；退貨A/B級商品出庫 |
| `shipments` | 全部商品出庫量 | 件；包含退貨商品和新單商品，不能直接當退貨履約量 |
| `goods_scrap` | 商品報廢量 | 件；品質檢查後C級商品退出 |
| `tote_scrap` | 循環箱報廢量 | 箱；與商品報廢不同 |
| `course_pass_ratio_mixed_units` | 課程混合通過比 | 比值；混合商品、箱與外包事件，可超過1，不作履約決策 |
| `returned_goods_resolution_ratio` | 退貨商品流量結案比 | 比值；跨期在製量可能使其略高於1，不是精確批次追蹤 |
| `returned_goods_end_wip` | 期末尚未完成的退貨商品 | 件；計算保守結案下界用 |
| `cohort_completion_lower_bound_pct` | 退貨批次結案率保守下界 | %；1−期末全部退貨商品在製量／觀察期退貨到達量，最低為0；含報廢結案，不等於出貨率。 |
| `all_goods_resolution_ratio` | 全部商品流量結案比 | 比值；包含新單商品與跨期影響 |
| `separator_blocked_pct` | 拆包設備阻塞時間占比 | %；觀察期被下游擋住的時間比例 |
| `washer1_util_pct` | 第一台清洗機加工占比 | %；觀察期處於加工的時間比例 |
| `washer2_util_pct` | 第二台清洗機加工占比 | %；未啟用第二台時應配合方案解讀 |
| `washer1_down_pct` | 第一台清洗機停機占比 | %；與加工、待機、阻塞不同 |
| `washed_internal` | 內部清洗完成量 | 箱；觀察期完成 |
| `washed_outside` | 外部清洗完成並返回量 | 箱；不要與外包送出量混淆 |
| `wash_energy_kwh` | 清洗設備用電 | 度電；觀察期能耗 |
| `conveyor_energy_kwh` | 輸送設備用電 | 度電；觀察期能耗 |
| `qa_queue_max` | 品質檢查待檢隊列最大值 | 件；觀察窗統計的最大隊列 |
| `qa_queue_mean` | 品質檢查待檢隊列平均值 | 件；時間加權平均 |
| `refurb_queue_max` | 整新待處理隊列最大值 | 件 |
| `refurb_queue_mean` | 整新待處理隊列平均值 | 件；時間加權平均 |
| `qtime_n` | 已開始品質檢查的等待樣本數 | 件；未開始檢查者仍有右設限 |
| `qtime_mean_s` | 平均檢查前等待 | 秒；外部到達至開始品質檢查 |
| `qtime_max_s` | 最長已觀測完整等待 | 秒；不能據此斷言所有未完成需求都不超時 |
| `over4h` | 等待超過4小時的觀測事件 | 件；開始品質檢查時入帳 |
| `over24h` | 等待超過24小時的觀測事件 | 件；尚未開始檢查者未取得完整等待時間 |
| `qtime_loss_ntd` | 超24小時貶值損失 | 新臺幣元；暖機後開始檢查時，等待超24小時按商品價值800×貶值率15%計算。 |
| `grade_A` | A級商品數 | 件；較簡單整理 |
| `grade_B` | B級商品數 | 件；需整新 |
| `grade_C` | C級商品數 | 件；拆解報廢 |
| `chi2` | 分級比例卡方統計量 | 無單位；比較觀測分類與60/30/10設定 |
| `chi2_p` | 分級檢定p值 | 0到1；不是改善方案P，也不是假設為真的機率 |
| `dispatches` | 支援調派次數 | 次；觀察期內實際觸發 |
| `returns_home` | 支援員歸建次數 | 次 |
| `outsourced` | 送出外包清洗量 | 箱；完整減碳公式的外包排放扣除此量 |
| `outsourced_returned` | 外包清洗返回量 | 箱；可能與送出量因跨期而不同 |
| `outside_wip_start` | 期初外包在途量 | 箱；仍屬系統工作量 |
| `outside_wip_end` | 期末外包在途量 | 箱 |
| `turnover` | 循環池周轉指標 | 比值；依模型完成清洗/回流量相對500箱計算，不是真實現地回收率 |

## 彙總與配置表

`方案比較.csv`每列是一組配置的一個指標：`metric`是原始指標名稱；`mean`是30次平均，`CI95_low`／`CI95_high`是平均的95%信賴上下界，`n`為30。不是每次模擬數值的最小／最大值。

`完整配置比較.csv`每列一組配置，含中文情境、方案、設備／人員／外包設定，以及主要指標平均與信賴上下界。年淨效益是與同情境現況配對年化，非本期收入。

`實驗配置.csv`的`replications`是規劃重複數，`warmup_s`／`stop_s`是暖機／停止秒數，`seed_rule`是種子規則。`基準精度600次.csv`前30筆與主實驗共用，不能將兩檔相加當1950次不重複運行。

`逐次守恆檢查.csv`含情境、方案、緩衝、重複編號及16個殘差。各殘差均應為0；物理與隊列面積驗證另列在逐次結果。公式及容差見[信效度報告](../信效度報告.md)。

## 分母與邊界

需求口徑以退貨到達量作分母，出庫替代口徑以全部已出庫量作分母；後者含新單，仍不是完整退貨批次生命週期盤查。箱與商品不可直接相加當履約。等待樣本只含已開始檢查者；未完成需求須看在製與待入場。

隊列平均為時間加權，不是每次事件的簡單平均。`qa_queue_warmup_carry_area`是跨暖機的面積邊界調整，不能當成驗證失敗。投資為0時投資報酬率不適用，年淨效益非正時沒有正回收期。
