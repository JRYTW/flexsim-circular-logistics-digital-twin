# 數據導覽

| 檔案 | 內容 |
|---|---|
| [方案比較.csv](方案比較.csv) | 短波尖峰情境下的主要方案平均與95%信賴區間 |
| [逐次實驗結果.csv](逐次實驗結果.csv) | 1350筆主實驗，各列代表一次模擬 |
| [基準精度600次.csv](基準精度600次.csv) | 同一基準配置的600個樣本，其中30個與主實驗共用 |
| [實驗配置.csv](實驗配置.csv) | 需求、方案、緩衝長度、重複次數與種子規則 |
| [已出庫口徑比較.csv](已出庫口徑比較.csv) | 以出庫量另算環境及成本指標 |
| [欄位說明](欄位說明.md)／[欄位對照.csv](欄位對照.csv) | 原始欄名、中文意思與單位 |

需求情境回答「來多少」，改善方案回答「怎麼改」。例如短波尖峰情境（S1）、聯合改善方案（P4）、12公尺緩衝，是一組配置。

比較表的平均值及95%信賴區間（CI）描述多次結果，不是單次的最大、最小值。暖機24小時後統計六天；主實驗45種配置各30次，含基準補充共1920次不重複運行。

研究數據採簡化搬運交接假設，用於比較改善方案；展示模型則包含實體輸送路徑。兩者的搬運時間假設不同，研究數據不能直接視為展示配置的績效。
