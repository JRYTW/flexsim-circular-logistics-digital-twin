# 數據導覽

本次使用含實體輸送與人員行走的原生模型，透過 FlexSim 2027 的批次實驗工具（Experimenter）完成三個需求情境、每情境15種配置，共45種配置×30次＝1350次主實驗。每次七天，前24小時暖機，後六天（518400秒）統計。基準配置另補足600次，前30次與主實驗共用，因此共1920次不重複運行。各配置共用種子規則：第r次使用101＋37×（r−1）。

## 口徑

表內「平均［下界, 上界］」為30次平均與其95%信賴區間；使用自由度29的t分布。區間描述平均估計的不確定性，不是單次運行的最小值與最大值。阻塞以觀察期拆包設備被下游擋住的時間占比計算；等待從外部退貨到達算到開始品質檢查。

清洗與輸送用電來自原生狀態累計時間；先在暖機與結束時讀取，再相減。待檢與整新隊列統計在暖機時重設，期末原生平均及最大值即是觀察窗讀值。等待紀錄只納入暖機後開始檢查的商品；未開始者須另看積壓。動態畫面與CSV有不同統計範圍，見[儀表板說明](../../模型/儀表板說明.md)。

所有數據均為教學設定下模擬結果，非倉庫實測。來源與檢查見[信效度](../信效度報告.md)，計算式見[環境與投資](../環境與投資評估.md)。

表格與簡報依版面顯示2至3位小數；差值與年化以未四捨五入值計算，因此可能和直接相減顯示值有最後一位差異。
