## 閱讀前：代號和數字怎麼看

**需求情境**：平日基準情境（S0）、短波尖峰情境（S1）、較高短波尖峰情境（S1_4.5）。**改善方案**：維持現況方案（P0）、增設第二台清洗機方案（P1）、僅加緩衝方案（P2）、外包清洗方案（P3）、聯合改善方案（P4，含緩衝、人員支援與觸發式外包）。

**表中「平均值 [下界, 上界]」**的方括號是平均值的 **95% 信賴區間（CI）**；「30 次」是同一配置重複模擬30次。它不是95%的單次運行結果所在範圍。

**單位**：m＝公尺，方案名稱中的8公尺／12公尺是緩衝長度；min＝分鐘，h＝小時，NT$＝新臺幣元。「百分點」是兩個百分比相減，與增加百分之多少不同。

**本文名詞速讀**

| 用語 | 中文意思 |
|---|---|
| CI | 信賴區間，用來表示平均估計的不確定性，不是單次結果的分布範圍 |
| WIP | 尚未完成的在製工作；要分商品、循環箱與外部請求 |
| ROI | 投資報酬率；相對現況的年化淨效益除以投資 |
| GUI | 軟體視窗介面 |
| Dashboard | 即時儀表板 |
| SA | 系統分析，整理流程、資料與假設 |
| PM | 專案管理，整理工作、進度與風險 |


不熟悉其他詞時，請看[完整名詞與代碼對照](../名詞與代碼對照.md)。原始程式、資料欄位和檔名保留原文，方便查核。
