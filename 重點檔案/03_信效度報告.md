## 閱讀前：代號和數字怎麼看

**S 表示需求情境**：S0＝平日基準，S1＝短波尖峰，S1_4.5＝較高短波尖峰。**P 表示改善方案**：P0＝維持現況、P1＝第二台清洗機、P2＝僅加緩衝、P3＝外包、P4＝緩衝＋人員支援＋觸發式外包的聯合改善。

**表中「平均值 [下界, 上界]」**的方括號是平均值的 **95% 信賴區間（CI）**；「30 次」是同一配置重複模擬30次。它不是95%的單次運行結果所在範圍。

**單位**：m＝公尺，方案名稱中的8m／12m是緩衝長度；min＝分鐘，h＝小時，NT$＝新臺幣元。「百分點」是兩個百分比相減，與增加百分之多少不同。

**本文名詞速讀**

| 用語 | 中文意思 |
|---|---|
| CI | 信賴區間，用來表示平均估計的不確定性，不是單次結果的分布範圍 |
| QA | 品質檢查工位 |
| Q-Time | 外部到達到開始品質檢查的等待時間 |
| WIP | 尚未完成的在製工作；要分商品、循環箱與外部請求 |
| Blocked | 下游接不走而造成的阻塞 |
| KPI | 關鍵績效指標 |
| SLA | 服務水準要求，本案指模型設定的門檻 |
| ROI | 投資報酬率；相對現況的年化淨效益除以投資 |
| ESG | 環境、社會與公司治理；本案主要研究環境面 |
| DOE | 實驗設計，也就是有系統地比較不同情境和方案 |
| PFM | 一輪模擬得到的績效量測值 |
| GUI | 軟體視窗介面 |


**版本與檢查編號**：版本V8是模型第八版；驗證表V1–V11是十一項檢查，驗證V8專指停機比例。

不熟悉其他詞時，請看[完整名詞與代碼對照](../名詞與代碼對照.md)。原始程式、資料欄位和檔名保留原文，方便查核。

# 外部審查逐項核對與修正｜2026-10-29

本次只修正結論、口徑、展示與文件索引，沒有改模型參數、重跑或替換正式1350次數據。另引用已完成的300件／小時七日壓力測試，不將它混入主DOE（實驗設計，也就是有系統地比較不同情境和方案）。

## 1. 24小時貶值損失：成立，但「極限平均僅20分鐘」不完全正確

主DOE 1350次的`over24h`與`qtime_loss_ntd`全為0，因此方案間「避免24h貶值」的實測節省也是0。負ROI（投資報酬率；相對現況的年化淨效益除以投資）的判讀要明說：本主DOE沒有量到這項收益，不代表現實中不存在這種損失，也不能臆測加長洪峰後就一定回本。

S1 Before平均Q-Time（外部到達到開始品質檢查的等待時間）為19.714 [17.795, 21.633]分鐘；較高尖峰S1_4.5 Before為42.102 [37.045, 47.159]分鐘。45組最大的群組平均是S1_4.5/P2/0 公尺，約42.58分鐘；單次重複平均最高80.07分鐘，觀測到已開始QA者最長等待2.919小時。故不能說全部極限情境平均都約20分鐘。

`Over24h`在開始QA時依逐件時間戳入帳；尚未開始QA的需求屬右設限，不能以事件計數0宣稱所有未完成需求都已證實等待不到24 小時。

核心痛點其實已有獨立壓力證據：300件／小時持續7日，超24h事件11925、貶值損失1431000元、外部積壓34185。這組是超負荷測試，不是30次配對DOE，不能拿它推估P4可省多少或算投資回收。新增長洪峰的處方實驗應另立方案、共同種子和30次重複；本次不為製造ROI而事後調整主實驗。

## 2. 42%與約74%：達標，但不是P4造成74%的改善

42%是課程給定門檻，沒有提供相同物理輸入下推導42%的計算條件，因此不是必須校準到42%的模型答案。課程公式為：

`淨減碳率 = 1 − [(清洗kWh＋輸送kWh)×0.495＋外包送出箱數×0.05] / (退貨到達量×0.35)`

S1/P0無外包；逐次先算每件能耗再取平均為0.184875145 kWh/件，代入`1−0.184875145×0.495/0.35`得到73.853%。若要剛好42%，在同一無外包口徑下每件能耗應約0.410101 kWh，明顯高於本設定的實測值。差距來自公式係數、能耗及比較基準，不能當作現場已證實的全面碳盤查收益。

主推P4 12m為73.995 [73.966, 74.023]%，其95%CI下界73.966%高於42%，按此課程口徑達標。但Before已是73.853%，P4額外提升只有0.141個百分點，不能宣稱P4讓Before再減碳74%。P4有外包事件，必須連外包碳項一起扣，不可只套用電力公式。

本口徑以退貨需求作分母，沒有完整涵蓋循環箱製造、回收運輸、設備生命週期等；大量未履約的壓力情境另看已履約口徑稽核，不能靠積壓美化減碳。

## 3. 單靠8m緩衝不夠：成立，補強聯合控制發現

S1/P2/8m阻塞7.609 [6.917, 8.301]%，未達1%；同長度P4/8m為0.951 [0.783, 1.118]%。這推翻「只加8m就能達標」的說法。

P4是人員支援、緩衝及觸發式外包等聯合控制。P4/8m平均外包110.8箱，P4/12m平均84.7箱；所以目前比較支持「P2單獨不足、P4聯合控制較有效」，不能把全部差異識別成人員支援的獨立因果效果。要分解人力與外包貢獻，需額外消融實驗。

## 4. 單一主結論：P4 12 公尺，附明確投資條件

對有強制SLA需求的場合，主推P4 12 公尺：阻塞95%CI上界0.856%低於1%；結案率下界亦符合門檻。P4 8m保留為低預算備選：符合原訂均值門檻，但阻塞CI上界1.118%未過額外風險限制。

12m相較P0年淨效益仍約−50937元，沒有正回收期。若決策要求正直接ROI，就不應立即投資；應先確認SLA價值與現地成本。8m不是從數據中刪除，而是移到備援解釋，不再並列兩個主推結論。

## 5. 熱力圖與100%循環使用率：命名及指標解讀需要修正

既有圖片是原生3D截圖，加上設備績效門檻著色：從開始至116100秒加工占比≥90%或阻塞≥1%者標紅。它不是連續空間熱力圖，也不是當下設備狀態，改稱「設備績效著色截圖」。

簡報新增真正的設備×改善前/After數值熱圖，取自同seed101、同116100秒的原生設備時間占比；加工0–100%、阻塞0–3.5%各自色階，不能跨色階比較顏色。它是截至截點的累計占比，不冒充暖機後六日平均。

原生Dashboard（即時儀表板）含40文字卡及WIP/清洗狀態圖，但文字卡視覺較弱，不能稱為所有卡片皆是圖形儀表。「循環使用率100%」實為循環箱出庫占比：模型只允許商品配循環箱出庫，故為結構性必然，不作處方成效證據，也不代表現實回收率100%。展示改以Q-Time、Blocked（下游接不走而造成的阻塞）、外部積壓、活躍資產、能耗與成本比較為主。

## 6. 洪峰規模：成立，並修正百分比語句

三波各20分鐘，一日共1小時；S1波外80/h、尖峰210/h。210/h是S0 60/h的3.5倍，即「增加250%」，不是增加350%；270/h才是60/h的4.5倍，即增加350%。若以S1波外80/h為基準，210/h為2.625倍。

暖機後6日觀察期，S1/P0平均退貨12270.03，S0/P0為8600.87，比例1.4266倍；不是整週持續3.5倍。簡報改稱「短波尖峰」；真正的持續超載另指V10 300/h七日測試。
