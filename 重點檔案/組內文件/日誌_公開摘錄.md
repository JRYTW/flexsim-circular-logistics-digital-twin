**本文名詞速讀**

| 用語 | 中文意思 |
|---|---|
| SLA | 服務水準要求，本案指模型設定的門檻 |
| ROI | 投資報酬率；相對現況的年化淨效益除以投資 |
| 實驗設計（DOE） | 實驗設計，也就是有系統地比較不同情境和方案 |
| GUI | 軟體視窗介面 |

| SA | 系統分析，整理流程、資料與假設 |
| PM | 專案管理，整理工作、進度與風險 |
