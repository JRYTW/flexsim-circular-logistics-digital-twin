# 圖片先看這些說明

`3D全景.png`是三維倉庫畫面；不是現地照片。`Before設備著色.png`／`After設備著色.png`分別是現況與主推聯合改善12公尺的同種子截點，紅色依累計設備占比門檻著色。

`設備績效熱圖與儀表比較.png`比較設備累計加工／阻塞占比：前是現況、後是12公尺聯合改善；加工和阻塞採不同色階。品質檢查站原代碼QA；整新一站、二站原代碼B1/B2。

`Dashboard.png`是即時儀表板：WIP表示尚未完成工作，Washer State表示清洗機狀態，Processing/Idle/Down分別是加工/待機/停機。畫面數字是截點，不是30次平均。「循環使用率100%」是模型限定循環箱出庫的結構指標，不是實際回收率。詳見[完整名詞對照](../../名詞與代碼對照.md)。
