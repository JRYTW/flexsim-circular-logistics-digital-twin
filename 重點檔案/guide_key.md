## 閱讀前：代號和數字怎麼看

**需求情境**：平日基準情境（S0）、短波尖峰情境（S1）、較高短波尖峰情境（S1_4.5）。**改善方案**：維持現況方案（P0）、增設第二台清洗機方案（P1）、僅加緩衝方案（P2）、外包清洗方案（P3）、聯合改善方案（P4，含緩衝、人員支援與觸發式外包）。

**表中「平均值 [下界, 上界]」**的方括號是平均值的 **95% 信賴區間（CI）**；「30 次」是同一配置重複模擬30次。它不是95%的單次運行結果所在範圍。

**單位**：m＝公尺，方案名稱中的8公尺／12公尺是緩衝長度；min＝分鐘，h＝小時，NT$＝新臺幣元。「百分點」是兩個百分比相減，與增加百分之多少不同。

**本文名詞速讀**

| 用語 | 中文意思 |
|---|---|
| QA | 品質檢查工位 |
| ROI | 投資報酬率；相對現況的年化淨效益除以投資 |
| ESG | 環境、社會與公司治理；本案主要研究環境面 |
| 實驗設計（DOE） | 實驗設計，也就是有系統地比較不同情境和方案 |
| Dashboard | 即時儀表板 |
| CSV | 可用試算表打開的文字資料表 |


**版本與檢查編號**：版本V8是模型第八版；驗證表V1–V11是十一項檢查，驗證V8專指停機比例。

不熟悉其他詞時，請看[完整名詞與代碼對照](../名詞與代碼對照.md)。原始程式、資料欄位和檔名保留原文，方便查核。

我們用 FlexSim 模擬「退貨商品整理＋循環箱清洗」的倉庫，研究尖峰塞車、服務品質、減碳與投資。這個資料夾只放 V8 正式重點，不混入歷史試驗。

## 10分鐘閱讀順序

1. 看 [成果簡報](01_成果簡報.pptx)，先理解問題與結論。
2. 讀 [最終回報](02_最終回報.md)，特別看保留的未達標。
3. 開 [改善前/改善後比較](數據/BeforeAfter_v8.csv)，對照平均值與95%信賴區間。
4. 看 [3D全景](圖片/3D全景.png) 與 [即時儀表板（Dashboard）](圖片/Dashboard.png)，想像流程怎麼走。

需要完整白話解說，讀上一層的 [guide.md](../guide.md)。審查修正見 [逐項核對](07_審查修正說明.md)，評分原件見 [組內文件索引](組內文件/PM_驗收與風險索引.md)。

## 五句話記住結果

- 商品與空箱分兩條路；五名人員與500箱資產有限。聯合改善方案（P4）含支援及觸發式外包，不將其效果全算成人力。
- 短波尖峰情境（S1）拆包阻塞從12.221%，降到8公尺緩衝的聯合改善方案（P4）的0.951%或12公尺的0.711%；品質檢查（QA）也是瓶頸，單加清洗機不足。
- 短波尖峰情境（S1）若有強制服務要求，主推12公尺緩衝的聯合改善方案（P4）；8公尺是符合原均值規則的低預算備選，正直接投資報酬率（ROI）未達。
- 服務改善，但直接投資報酬率（ROI）為負，65%包材節約未達；不能把避免設備支出說成利潤。
- 主實驗1350次，加570次新基準，合計1920次；原30次精度未過，600基準補充通過。

CSV（可用試算表打開的文字資料表）中的`mean`是多次平均，`CI95_low`／`CI95_high`是平均估計的95%信賴界線。逐次實驗CSV每列是一次重複；BeforeAfter CSV每列是一組方案的一個指標。

影片與圖片都來自原生3D或原生即時儀表板（Dashboard）匯出。影片不是全桌面錄影；即時截點不是七日實驗平均。資料是模擬產生，不是真實客戶訂單。

## 完整模型在哪裡？

公開版已加入[四個原生模型與同名結果資料庫](../模型/README.md)：第一次開「循環物流_3D展示.fsm」，看批次結果則開「循環物流_實驗完整結果.fsm」並保留同名.sqlite。需要合法授權的FlexSim 2027；重跑前請先複製模型、資料庫與輸出資料夾。不附軟體、授權、原始課程教材或本機設定。
