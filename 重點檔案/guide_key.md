# 精華導覽：第一次看，從這裡開始

我們用 FlexSim 模擬「退貨商品整理＋循環箱清洗」的倉庫，研究尖峰塞車、服務品質、減碳與投資。這個資料夾只放 V8 正式重點，不混入歷史試驗。

## 10分鐘閱讀順序

1. 看 [成果簡報](01_成果簡報.pptx)，先理解問題與結論。
2. 讀 [最終回報](02_最終回報.md)，特別看保留的未達標。
3. 開 [Before/After比較](數據/BeforeAfter_v8.csv)，對照平均值與95%信賴區間。
4. 看 [3D全景](圖片/3D全景.png) 與 [Dashboard](圖片/Dashboard.png)，想像流程怎麼走。

需要完整白話解說，讀上一層的 [guide.md](../guide.md)。

## 五句話記住結果

- 商品與空箱分兩條路，最後一件配一箱；五名人員與500箱資產都有資源限制。
- S1拆包阻塞從12.221%，降到P4 8m的0.951%或12m的0.711%；QA也是瓶頸，單加清洗機不足。
- 看原訂均值門檻選8m；額外要求阻塞95%信賴上界<1%才選12m。
- 服務改善，但直接ROI為負，65%包材節約未達；不能把避免設備支出說成利潤。
- 主實驗1350次，加570次新基準，合計1920次；原30次精度未過，600基準補充通過。

## 完整模型在哪裡？
