# 展示指南

## 建議順序

1. 用[倉庫全景](模型畫面/01_全景.png)說明商品與循環箱的雙流程。
2. 在FlexSim開啟[原生模型](../模型/循環物流.fsm)，保持停止，依正面、左右側、背面及俯視查看空間。
3. 放大[分級交接](模型畫面/07_分級交接近景.png)、[包裝交接](模型畫面/08_包裝交接近景.png)與[上層交接](模型畫面/10_上層交接近景.png)。
4. 以[方案比較](數據/方案比較.csv)介紹阻塞與等待，再解釋減碳、成本和投資條件。
5. 用[成果簡報](成果簡報.pptx)收斂研究建議與適用範圍。

## 畫面判讀

正面低視角看支腳是否落在地面或平台；左右側看上下行輸送與末端接合；背面看樓梯、護欄與平台；俯視看分流、合流及地面通道。平台剖視圖暫時隱藏樓板，方便看下層，正常模型仍有平台。

設備顏色或單一畫面不能取代六日觀察期的多次平均。研究數據採簡化搬運交接假設，不能將它直接當成實體展示配置的績效；也不要把靜態畫面說成已驗證的連續動畫。
