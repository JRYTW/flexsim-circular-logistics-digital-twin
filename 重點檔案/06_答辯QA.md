## 閱讀前：代號和數字怎麼看

**需求情境**：平日基準情境（S0）、短波尖峰情境（S1）、較高短波尖峰情境（S1_4.5）。**改善方案**：維持現況方案（P0）、增設第二台清洗機方案（P1）、僅加緩衝方案（P2）、外包清洗方案（P3）、聯合改善方案（P4，含緩衝、人員支援與觸發式外包）。

**表中「平均值 [下界, 上界]」**的方括號是平均值的 **95% 信賴區間（CI）**；「30 次」是同一配置重複模擬30次。它不是95%的單次運行結果所在範圍。

**單位**：m＝公尺，方案名稱中的8公尺／12公尺是緩衝長度；min＝分鐘，h＝小時，NT$＝新臺幣元。「百分點」是兩個百分比相減，與增加百分之多少不同。

**本文名詞速讀**

| 用語 | 中文意思 |
|---|---|
| CI | 信賴區間，用來表示平均估計的不確定性，不是單次結果的分布範圍 |
| QA | 品質檢查工位 |
| SLA | 服務水準要求，本案指模型設定的門檻 |
| ROI | 投資報酬率；相對現況的年化淨效益除以投資 |
| 實驗設計（DOE） | 實驗設計，也就是有系統地比較不同情境和方案 |
| CAD | 電腦輔助設計圖 |
| Process Flow | 安排事件與任務的流程控制圖 |
| LCA | 生命週期評估 |


**版本與檢查編號**：版本V8是模型第八版；驗證表V1–V11是十一項檢查，驗證V8專指停機比例。

不熟悉其他詞時，請看[完整名詞與代碼對照](../名詞與代碼對照.md)。原始程式、資料欄位和檔名保留原文，方便查核。

1. 為什麼不是玩具模型？原生雙輸送閉環、分離/配對、5員A星尋路法（A*）移動、實際故障、有限箱池、外包延遲、流程控制圖（Process Flow）與1920次原生運行均有讀回。仍未獲實倉資料，不能冒稱現地校準。
2. 真正瓶頸？品質檢查（QA）單人40秒=90/h，清洗含故障期望115.2/h；尖峰同時有空箱回堵，單加洗機不足。
3. 支援真的有走路？TASKTYPE_TRAVELTOLOC移到品質檢查（QA）入口，抵達才20秒；200段均到邊緣0.5 公尺。
4. 怎麼證明防死鎖？指定路格原生硬單行；86797活動占用無重疊、972625路徑邊無逆向；主實驗（DOE）最長零出庫1 小時。有限測試不能證明所有可能死鎖不存在。
5. 靜止人員能被穿越？採官方人員讓位語義，忽略待命者的阻擋；活動旅行者仍互斥分配。若現場不允許讓位，需重新標定與驗證。
6. 500箱有硬限制？資產入庫閘控，外部請求先等；5箱縮小池停機最高5、恢復後出庫40，資產警告0。
7. V5全部過了嗎？沒有。主30次最差18.07%未達5%，固定600次補充12KPI最差3.47%，未把原失敗改成成功。
8. 1920怎麼算？1350主實驗＋570新增基準；基準600包含既有30，不能加成1950個獨立運行。
9. 100%通過嗎？混合商品/箱的原課程比率可能>100%；決策採保守結案下界，不假裝精確批次追蹤100%。
10. 主推哪個？短波尖峰情境（S1）強制服務水準要求（SLA）時主推12 公尺；8公尺只作低預算備選。原均值規則最低8公尺仍保留，但其信賴區間（CI）上界1.118%未過額外風險限制。若要求正直接投資報酬率（ROI）則不建議立刻投資。
11. 投資報酬率（ROI）如何？8公尺年淨效益約−64374元，12 公尺−50937元，均無正回收期。相較增設第二台清洗機方案（P1）少資本支出142/138萬元是避免支出，不是利潤。
12. 為什麼65%失敗？2%逐次報廢使期望壽命47.59次，完全沖銷資產後理想節約上限約47.89%；不能硬湊65%。
13. 碳數字可信嗎？依課程0.495等固定係數與狀態能耗，完整減碳扣洗、輸送、外包；非完整LCA（生命週期評估）。大量未履約時另用已履約分母稽核。
14. 五倍壓力怎樣？300件／小時跑七日，品質檢查（QA）先超載、外部積壓34185、超24h11925；資產仍守恆但服務水準要求（SLA）失敗，不能聲稱負荷無上限。
15. 下一步部署？取得CAD（電腦輔助設計圖）、到達/工時/故障/路徑與帳務紀錄，外部驗證後再決定服務價值能否覆蓋負投資報酬率（ROI）。現有產物可作課程比較與假設決策，不能直接承諾實倉改善額度。


16. 為什麼24小時損失沒改善？主實驗（DOE）的1350次原本就全0，沒有可量到的貶值收益；短波尖峰情境（S1） Before19.71 分鐘、高尖峰Before42.10 分鐘。獨立300件／小時七日壓力有11925超24小時與1431000元損失，但沒有聯合改善方案（P4）配對對照，不可挪用為投資報酬率（ROI）。
17. 為什麼42%變74%？42%是門檻；改善前每件能耗0.184875kWh，代入給定0.495與0.35公式即73.853%。12公尺：73.995%，比改善前僅+0.141個百分點；不是完整LCA。
18. 8公尺有效是緩衝本身嗎？僅加8公尺緩衝方案（P2）仍7.609%阻塞，單獨不達標；聯合改善方案（P4）同8公尺：0.951%。聯合改善方案（P4）有平均110.8箱外包，不能全歸因於支援員。
19. 熱力圖真的嗎？舊3D圖改稱設備績效著色截圖；新表格熱圖有真實設備時間占比與明示色階。100%循環箱出庫占比是結構指標，不是回收率或改善效果。
20. 暴增350%怎麼算？210件／小時相對60件／小時是3.5倍，即增加250%；270件／小時才增加350%。每波20 分鐘，六日總量約1.43倍；長期超載是另一組300件／小時測試。
