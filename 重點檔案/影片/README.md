# 影片怎麼看

`原生3D運行.webm`是330.752秒的三維模擬畫面，由3600張原生影格組成，不是全桌面錄影，也不是實倉監視器。

`逐格模型時間與狀態.csv`是錄製追蹤，沒有標題列；本次不改動原始證據。各欄依原錄製腳本順序記錄：影格編號、模型時間（秒）、錄製時鐘值、品質檢查待檢量、支援調派次數、支援狀態、累計出庫。它用來證明畫面隨模型時間前進，不能當作正式30次績效統計。模型物件與指標的意思見[完整名詞對照](../../名詞與代碼對照.md)。
